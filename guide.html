01 / FESTIVAL PLAYLIST

이번 주에 탈 차부터 찾자.

레페의 한마디메인의 페스티벌 추천에서 도전·메인1·메인2·PR 스턴트에 맞는 튜닝을 찾아봐. 추천 카드에는 공유 코드가 바로 보여서 펼치지 않고도 복사할 수 있어.

02 / FIND → CHECK → COPY

튜닝을 가져가는 세 단계.

1. 찾기
차량명·제조사·콘셉트·공유 코드 검색
예: Honda S800

전체 차량 목록에서 검색해봐. PI·분류·구동·용도·연대 필터로 후보를 좁힐 수도 있어.

2. 확인하기
Honda S800 1970
PI · 구동방식 · 용도
상세 ↗

차량명이나 상세 버튼을 누르면 성능 수치, 빌드 콘셉트, 주행 평가와 튜닝 메모를 볼 수 있어.

3. 코드 복사
공유 코드128 413 839코드 복사

공유 코드를 복사해서 게임의 튜닝 검색에 입력해. 모바일 전체 목록에서는 화살표로 코드 영역을 펼치면 돼.

위의 작은 패널은 사용 순서를 설명하는 예시야.

레페의 팁같은 차량에도 튜닝이 여러 개 있을 수 있어. 이름만 보지 말고 PI와 용도, 주행 평가도 같이 확인해줘.

03 / READ THE RECORDS

기록은 같은 조건끼리 비교해.

순위표에서 먼저 볼 숫자1:47.559평균 대비 -2.534%

기록 아래의 음수는 같은 PI·같은 테스트 코스의 아카이브 평균보다 시간이 짧다는 뜻이야. 이 예시는 평균보다 약 2.53% 빠른 기록이지.

PI · 코스 · 차량 성격

온로드와 오프로드 테스트 기록은 각각의 코스 안에서 비교해. 평균 대비 %는 아카이브에 등록된 기록을 기준으로 계산해.

전체 게임 이용자 중 상위 몇 %라는 뜻은 아니야. 실제 이벤트에 맞는지는 차량의 용도와 메모도 함께 보자.

설치 메뉴가 안 보여요.

디코·메신저 안의 화면이라면 주소를 복사해 위에서 선택한 브라우저로 다시 열어봐. PC에서는 주소창 아이콘 대신 메뉴 경로를 이용할 수 있어. iPhone·iPad는 공유 목록 아래까지 내려보고, ‘홈 화면에 추가’가 없으면 ‘동작 편집’을 확인해줘. 이미 설치되어 있는지도 홈 화면이나 브라우저 앱 목록에서 찾아봐.

설치했는데 아이콘이 어디 있는지 모르겠어요.

휴대폰은 홈 화면과 앱 목록에서 Forza 아카이브를 찾아봐. PC Chrome은 chrome://apps, Edge는 edge://apps를 주소창에 입력하면 설치된 앱을 확인할 수 있어. 필요하면 거기서 바로가기를 만들거나 고정해줘.

05 / QUESTIONS

필요할 때 펼쳐봐.

차가 너무 많아서 찾기 어려워.

검색과 필터를 함께 써봐. 전체 목록은 30개씩 페이지로 나뉘고, 조건을 바꾸면 첫 페이지부터 보여줘. 모바일에서는 코드를 접어둬서 목록을 짧게 훑을 수 있어.

이번 주 차량이 ‘미분류’에 보여.

이벤트 그룹 값이 없는 차량도 빠뜨리지 않도록 미분류에 표시해. 차량 상세와 이벤트 이름을 함께 확인해줘.

더 자세한 질문이나 튜닝 피드백은?

상단 패독에서 디스코드 소개를 볼 수 있어. 튜닝 피드백과 주행 이야기는 그쪽에서 함께 나누자.
