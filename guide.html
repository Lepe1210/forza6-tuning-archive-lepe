이번 주 페스티벌 차량을 찾거나, 원하는 차량의 공유 코드와 주행 평가를 확인하는 것이 이 사이트의 가장 기본적인 사용법입니다.

1. 이번 주 차량 찾기

메인 화면 가장 위의 페스티벌 튜닝차량에서 현재 시즌에 사용하는 추천 차량을 확인할 수 있습니다.

2. 원하는 차량 검색하기

검색창에 제조사, 차량명, 콘셉트 또는 공유 코드를 입력하면 전체 튜닝 DB에서 원하는 차량을 찾을 수 있습니다.

3. 차량 카드를 눌러 상세 확인

차량 카드를 선택하면 공유 코드, 성능 수치, 빌드 콘셉트, 주행 평가, 튜닝 메모와 테스트 기록을 자세히 볼 수 있습니다.

4. 조건이 많다면 필터 사용

PI, 차량 분류, 구동방식, 용도 등의 필터를 함께 사용하면 원하는 조건의 차량만 빠르게 추릴 수 있습니다.

INSTALL AS APP

휴대폰이나 PC에 앱처럼 설치하기

Forza 6 Tuning Archive는 별도의 앱스토어 다운로드 없이 지원되는 브라우저에서 홈 화면이나 앱 목록에 설치해 사용할 수 있습니다.

Android / Chrome

사이트를 Chrome으로 연 뒤 브라우저 메뉴에서 앱 설치 또는 홈 화면에 추가를 선택합니다.

설치가 완료되면 일반 앱처럼 홈 화면 아이콘으로 실행할 수 있습니다.

iPhone / iPad

Safari에서 사이트를 연 뒤 공유 버튼 → 홈 화면에 추가를 선택합니다.

홈 화면에 생성된 아이콘을 누르면 앱과 비슷한 형태로 실행됩니다.

Windows / Chrome · Edge

지원되는 브라우저에서는 주소창 주변 또는 브라우저 메뉴에 앱 설치 항목이 표시될 수 있습니다.

설치하면 시작 메뉴나 바탕화면에서 별도 창으로 실행할 수 있습니다.

설치 버튼이 안 보인다면?

브라우저와 운영체제 버전에 따라 메뉴 이름이나 설치 방식이 조금 다를 수 있습니다. 최신 Chrome, Edge 또는 Safari 사용을 권장합니다.

FESTIVAL PLAYLIST

페스티벌 튜닝차량

매 시즌 페스티벌 플레이리스트 진행에 사용할 차량을 모아두는 영역입니다.

현재 시즌 추천

메인 화면 상단에서 이번 시즌에 준비된 튜닝 차량을 바로 확인할 수 있습니다. 차량 카드를 누르면 해당 튜닝의 상세 정보도 볼 수 있습니다.

지난 시즌 보기

지난 시즌 튜닝 보기 버튼을 누르면 이전 페스티벌 시즌에 사용했던 차량 기록을 확인할 수 있습니다.

SEARCH & FILTER

차량 검색과 필터

전체 차량 DB가 많아졌다면 검색과 필터를 함께 사용하는 것이 가장 빠릅니다.

검색창

차량명, 제조사, 빌드 콘셉트, 공유 코드 등을 입력해 원하는 튜닝을 검색할 수 있습니다.

PI 필터

D 400부터 X 999까지 원하는 성능 등급의 차량만 표시합니다.

차량 분류

핫 해치, GT, 랠리, 슈퍼카, 픽업 및 4×4 등 게임 내 차량 분류를 기준으로 검색할 수 있습니다.

구동방식 / 용도

FWD, RWD, 4WD 또는 온로드, 오프로드, 혼합 등 원하는 성격의 튜닝만 따로 볼 수 있습니다.

연대별 필터

60년대, 70년대, 80년대, 90년대, 00년대, 10년대, 20년대와 기타 차량으로 나누어 검색할 수 있습니다.

필터 초기화

조건을 너무 많이 선택했거나 다시 전체 차량을 보고 싶다면 필터 초기화 버튼을 사용하면 됩니다.

TEST RECORDS

테스트 기록 보는 법

튜닝 차량의 성능을 비교하기 위한 공통 테스트 코스를 사용합니다.

레전드 섬 서킷

온로드 차량의 기본적인 성능을 비교하는 테스트 코스입니다. 차량 상세창과 PI별 기록 순위에서 확인할 수 있습니다.

세키베 타임어택

오프로드 차량을 중심으로 사용하는 테스트 코스입니다. Dirt와 Cross Country 계열 차량의 성능을 볼 때 참고할 수 있습니다.

PI별 평균 기록

같은 PI 등급 차량들의 평균 기록과 최고 기록을 계산해 표시합니다. 기록 순위를 펼쳐 전체 차량의 위치도 확인할 수 있습니다.

기록이 전부는 아닙니다

테스트 기록은 차량의 성격을 판단하기 위한 참고 자료입니다. 실제 코스 특성, 구동방식, 출력, 무게와 튜닝 콘셉트에 따라 체감 성능은 달라질 수 있습니다.

TUNE DETAILS

차량 상세창

차량 카드를 누르면 단순 공유 코드 외에도 해당 빌드의 성격을 확인할 수 있습니다.

공유 코드

게임에서 튜닝을 바로 찾을 수 있는 9자리 공유 코드를 제공합니다.

성능 정보

출력, 중량, 횡가속도와 구동방식 등 차량의 주요 정보를 확인할 수 있습니다.

빌드 콘셉트 / 평가

어떤 방향으로 만든 차량인지, 실제 주행에서 어떤 특징이 있었는지를 정리합니다.

튜닝 메모

기어비, 거동, 특이사항 등 차량을 사용할 때 알아두면 좋은 내용을 기록합니다.
